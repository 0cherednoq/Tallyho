# Руководство пользователя tallyho

tallyho — async-библиотека для Python и PostgreSQL. Она добавляет к брокеру задач то, чего в нём
обычно нет: учёт группы задач (батчи и вложенные батчи), прогресс, финализацию ровно один раз,
динамический fan-out, конвейеры этапов и транзакционные хуки, которые переносят итог и прогресс
в ваши таблицы.

Исполнение задач, ретраи, расписания и rate limit остаются за брокером. Бизнес-статусы и
бизнес-данные остаются в ваших таблицах: tallyho хранит только техническое состояние группы задач.

## О примерах

Блоки кода в руководстве бывают двух видов:

* **исполняемые** — извлекаются из страниц и выполняются в CI на настоящем PostgreSQL со встроенным
  `InlineBroker`. В таком блоке уже определены `engine` (`AsyncEngine` SQLAlchemy) и `schema`
  (имя пустой схемы); в своём проекте вы создаёте их сами. `await` на верхнем уровне блока
  означает «внутри вашей `async`-функции»;
* **иллюстративные** — фрагменты, которым нужен воркер брокера, pgbouncer или структура вашего
  проекта. Они показывают, куда вставить код, и отдельно не выполняются.

Имена импортов во всех блоках настоящие: исполняемые примеры падают в CI, если API изменился.
