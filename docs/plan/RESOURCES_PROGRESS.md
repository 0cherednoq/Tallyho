## Открытые вопросы владельцу

| # | Вопрос | Почему нужен ответ до реализации |
|---|---|---|
| 1 | Значения по умолчанию `max_defers` и `max_deferred_for` | предложение — ~20 отложений / ~сутки, по образцу Sidekiq Enterprise (`../resource-management-research.md` §1). Нужно подтвердить порядок, он определяет, когда работа сдаётся вместо ожидания |
| 2 | `deadline_mode` по умолчанию | предложение — `"wall"` (обратная совместимость). Если дедлайны в проектах уже используются с расчётом на активное время, умолчание другое |
| 3 | Ставить ли `defer` в счётчики (кумулятивное число отложений) | план этого **не** делает: гейдж по `th_outbox` достаточен, а колонка счётчика трогает горячий путь группового коммита (§9.2). Если нужна метрика «сколько раз откладывали за всё время» — отдельная задача |
