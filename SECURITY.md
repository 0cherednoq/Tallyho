# Политика безопасности

## Поддерживаемые версии

До выпуска стабильной версии исправления безопасности публикуются только для последнего релиза.

## Как сообщить об уязвимости

Не создавайте публичный issue с деталями уязвимости. Используйте
[Private vulnerability reporting](https://github.com/0cherednoq/tallyho/security/advisories/new).

Укажите затронутую версию, минимальный сценарий воспроизведения, возможные последствия и известный
вам способ обхода. Подтверждение получения и дальнейший статус будут переданы через private advisory.
